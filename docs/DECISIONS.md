## 2026-09-05 14-1 実装方式の改訂: 匿名認証 → 固定アカウントへのパスワード認証
- 花園から全権委任を受けたセットアップ自動化の中で、実装を次のとおり改訂した
  - 利用者3名ぶんの認証アカウントをSupabaseに事前作成（形式上のメール + パスワード =「4桁 + 固定接尾辞」）
  - 「はじめる」画面は本人選択 → 4桁入力 → そのアカウントへログイン
- 理由: ①手作業だった「Anonymous Sign-ins有効化」が不要になる
  ②サービスロールキーが実行時に不要になる ③端末ごとに独立ログインでき紐付け替えが不要
- セキュリティ強度は決定どおり「4桁」のまま。値はリポジトリに存在しない
  （`supabase/setup/create_auth_users.sql` はプレースホルダのみ。実行済み）
- あいことばの変更方法は同ファイル末尾のSQLコメント参照
- 環境変数 APP_PASSCODE は不要になったため削除
