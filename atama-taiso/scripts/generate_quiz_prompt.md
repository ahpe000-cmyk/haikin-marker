# クイズ問題 生成プロンプト（花園がChatGPT/Claudeに貼って使う）

CLAUDE.md §9 の手順1。カテゴリごとに下のプロンプトを貼り、出力されたCSVを
`data/quiz_draft.csv` に追記していく。**必ず人の目で内容を確認してから**
`npm run seed:quiz -- data/quiz_draft.csv` で投入する（確認前の投入はしない）。

## 使い方

1. 下の「プロンプト本文」の `{カテゴリ}` を1つ選んで置き換える
   - `math`（かんたんな計算）
   - `history`（日本の歴史の常識）
   - `geography`(日本の地理の常識)
   - `heritage`（日本の世界遺産・名所）
   - `general`（ことわざ・季節・生活の常識）
2. ChatGPT または Claude に貼る。1回で50問ずつ、4回くり返して200問集める
3. 出力の1行目（ヘッダー）は最初の1回だけ残し、2回目以降は削って追記する
4. 全問に目を通し、まちがい・不適切・難しすぎる問題は行ごと削除する

## プロンプト本文

```
あなたは60〜70代の日本人向けの、やさしい常識クイズを作る係です。
カテゴリ「{カテゴリ}」の4択クイズを50問、CSV形式だけで出力してください。

ルール:
- 1行目はヘッダー: category,question,choice1,choice2,choice3,choice4,answer_index,explanation,difficulty
- category は「{カテゴリ}」で固定
- question は60〜70代が読みやすい、短くやさしい日本語。漢字には頼りすぎない
- 選択肢は4つ。まぎらわしすぎない。正解は choice1〜choice4 のどれかに置き、
  answer_index に 0〜3 で示す（choice1なら0）。正解の位置は毎回バラバラにする
- explanation は正解の一言解説（30字以内）
- difficulty は 1（やさしい）〜3（すこし難しい）。1と2を中心にする
- 事実として正しい問題だけを出す。あいまいな説・最近変わった事柄は避ける
- 実在の個人名は使わない。政治・宗教・病気・死・お金の損得の話題は避ける
- 医療や健康の効能にふれない
- フィールドにカンマを含む場合は "二重引用符" で囲む
- CSV以外の文章（あいさつ・説明）は一切出力しない
```

## 確認のときに見るところ（手順3）

- 正解が本当に正しいか（あやしい問題は削除）
- answer_index の位置が合っているか
- 読みにくい・長すぎる・意地悪な問題はないか
- 同じ問題・ほぼ同じ問題の重複はないか
